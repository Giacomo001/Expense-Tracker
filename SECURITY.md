# Security Policy

## Overview

This repository is a personal project created for learning and experimentation purposes. While this software is provided as-is without formal support guarantees, security concerns are still taken seriously.

## Supported Versions

Only the latest version available on the `main` branch is actively maintained. 

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please report it privately rather than creating a public issue.

### How to Report Privately

Please use GitHub's built-in private reporting feature:

1. Go to the **Security** tab of this repository.
2. Click on **Vulnerability reporting** in the left sidebar.
3. Click **Report a vulnerability** to submit your report confidentially.

### What to Expect

* **Response Time:** Since this is a personal side project, reports will be reviewed on a best-effort basis (typically within a few days).
* **Fixes & Disclosure:** If confirmed, a fix will be developed privately and released as soon as possible. Please allow time to address the issue before sharing any details publicly.

Thank you for helping keep this project secure!
